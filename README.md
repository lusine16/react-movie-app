# 🎬 React Movie App

A movie web application built with **React, TypeScript, and Redux Toolkit**. The app allows users to explore movies, browse genres, view movie details, search for films, and manage their favorite movies.

## ✨ Features

- **Movie Discovery** — Explore movies and view movie information.
- **Genre Browsing** — Browse movie genres and discover films by category.
- **Movie Details** — View information about individual movies, including descriptions, directors, production details, and financial information when available.
- **Search** — Search for movies using the header search interface.
- **User Authentication** — Sign in and access your account.
- **Favorites** — View and manage favorite movies.
- **Responsive UI Components** — Reusable components for a consistent interface.
- **Loading States** — Display loading indicators while data is being fetched.
- **API Integration** — Retrieve movie data and user information from an API.
- **Type Safety** — Use TypeScript to improve code reliability and maintainability.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/lusine16/react-movie-app.git
   ```

2. Navigate to the project directory:

   ```bash
   cd react-movie-app
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

**Note:** If the application requires API credentials or environment variables, configure them according to the project's setup before running the app.
